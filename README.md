# InmoControl

Sistema integral de gestión y administración inmobiliaria para control de arrendadores, arrendatarios, propiedades, contratos y liquidaciones.

## 🚀 Tecnologías

- **Frontend**: React 18 + TypeScript + Vite + Tailwind CSS + Lucide Icons
- **Desktop**: Tauri / Rust & Windows Desktop wrapper
- **Persistencia**: Local JSON storage & state management
- **Generación de Reportes**: jsPDF / html2canvas para liquidaciones y recibos

## 📦 Instalación y Desarrollo

### Requisitos
- Node.js (v18+)
- npm / yarn / pnpm
- Rust / Cargo (para compilar con Tauri)

### Pasos

1. Instalar dependencias:
   \\\ash
   npm install
   \\\

2. Ejecutar en modo desarrollo:
   \\\ash
   npm run dev
   \\\

3. Compilar para producción:
   \\\ash
   npm run build
   \\\
